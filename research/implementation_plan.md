# 研究与实现计划

依据用户完整任务书直接执行；无远程发布。使用现有空白工作区，不需要隔离已有代码。

1. 读取作业 PDF、核验原始文献，保留来源和失败记录。
2. 先写授权硬约束、风险边界、执行前篡改与撤销、审计和指标测试，运行观察失败，再实现模块。
3. 独立潜在场景生成标签，风险信号是带噪观测；30 个独立种子，每种子 10000 条。固定边界和全因子样本只作确定性测试。
4. 实施主比较、阈值扫描、交互风险、两个消融、权重与生成机制敏感性。种子为配对 Bootstrap 单位，报告 Monte Carlo 不确定性。
5. 从结果表生成论文、图表、DOCX 与 PDF，12pt 正文，最多20页。完成代码复跑、引用、数值和排版审查。

研究决策：S 在原始数据中表示任务一致性，评分使用 1-S；OBSERVE 属无人干预执行，主指标合并 AUTO_EXECUTE 与 OBSERVE 并同时输出细分。
审计完整率衡量字段完备，不代表防篡改能力。SHA256 对比只在可信决策记录与执行门不可绕过的假设下有效，不宣称密码学认证。
H2 在预设安全目标下比较测试集表现，阈值仅用独立校准种子选择，不能事后选择有利点。H3 允许不获支持。
